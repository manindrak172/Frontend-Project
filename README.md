# 🎬 Movie Booking Website

A frontend-based **Movie Booking Website** developed using **HTML, CSS, and JavaScript**. The project provides a simple interface for browsing movies, viewing movie details, selecting theatres and seats, making payments, and receiving booking confirmation.

## 🚀 Features

* 🏠 Home page
* 🎥 Movies listing
* 📄 Movie details
* 🔐 Login page
* 🏢 Theatre selection
* 💺 Seat selection
* 💳 Payment page
* ✅ Booking confirmation
* 📱 Responsive user interface
* 🎨 Clean and simple design

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## ⚙️ How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a web browser.
4. Explore the movie booking website.

## 🎯 Project Objective

The objective of this project is to create a user-friendly frontend interface for an online movie booking system and demonstrate practical implementation of **HTML, CSS, and JavaScript**.
